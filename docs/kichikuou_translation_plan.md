# 《鬼畜王兰斯》汉化工程现行计划

状态：**现行、权威**

生效日期：2026-08-14

本文档规定正式汉化工程的来源、继承边界、实施流程和进度口径。项目内其他汉化文档如与本文冲突，以本文为准。

## 1. 核心决策

1. 官方日文版反编译得到的 ADV 是唯一权威原文和脚本基线。
2. 正式中文译文、译名和术语从零开始，不继承旧半汉化版或既有中文 PoC 的任何文本成果。
3. 继续采用“日文原版解包 → UTF-8 重编码 → `unicode = true` 编译 → `xsystem35-sdl2` 运行”的技术路线。
4. 可以继承已经验证的工具链、编码迁移、构建、字体显示、排版和 QA 探索结论。
5. 所有正式 ADV 和 SA.ALD 都从只读日文基线、当前翻译数据库和当前工具重新生成，不手工维护混合中文 ADV。

这里的“从零开始”专指中文文本成果。已经完成的日文基线校验和 Unicode 运行验证仍然有效，但不计入译文完成度。

## 2. 权威输入与隔离边界

正式输入：

- 官方日文原始文件：`workspace/kichikuou-jp/disc/`
- 版本控制中的正式日文脚本基线：`adv_scripts/project/`
- 空白正式翻译目录：`workspace/translation/catalogs/adv-v1/`
- 日文原词候选：`workspace/translation/glossary/jp-source-v1/`
- 文本工具：`tools/adv_text.py`、`tools/adv_glossary.py`

`workspace/kichikuou-jp/decompiled/` 和 `workspace/utf8-migration/project/` 保留为独立验证记录，不再作为日常正式构建输入。正式构建只读取重新生成并纳入版本控制的 `adv_scripts/project/`。

以下目录属于历史研究资料，禁止作为译文、译名、术语或正式构建输入：

- `workspace/src/`
- `workspace/unpacked/`
- `workspace/kichikuou-jp/chinese-recovered-source/`
- `workspace/translation/chinese-recovered-utf8/`
- `workspace/translation/alice-poc/`

历史目录可以保留以复核旧包结构、混合编码、字体和 QA 结论，但不得向正式翻译目录复制中文文本。

## 3. 可继承与作废内容

继续有效：

- 官方日文光盘、ALD 和 ADV 的哈希及 manifest。
- CP932 反编译/回编译验证。
- 201 个 ADV 的 UTF-8 Unicode 双构建和语义回读验证。
- `xsystem35-sdl2` 下标题、新游戏、菜单、分支和存读档冒烟结果。
- 语法感知的文本提取、安全回填、占位符保护和术语提取方法。
- 中文字体覆盖、字重、换行、溢出和进程重启后加载配置等测试经验。
- 测试目录与正式存档隔离、构建复现和 QA 记录方法。

作废且不得继承：

- 旧半汉化版的全部中文对白、旁白、菜单和系统文本。
- Alice 之馆 PoC 的 56 行测试译文及其临时译名。
- 从旧中文脚本产生的翻译记忆、中文术语和译名映射。
- 当前混合汉化 ADV 上的标签或变量修复；除非以后能在官方日文基线上独立复现问题并重新验证。
- “第四测试版”“汉化至利萨斯内战”等旧进度口径。

## 5. 正式实施流程

```text
官方日文只读基线
        ↓
提取空白文本目录和日文术语候选
        ↓
从零批准中文术语
        ↓
按连续场景翻译、校对和审核
        ↓
安全回填到官方 ADV 的生成副本
        ↓
Unicode 编译和 SA.ALD 封包
        ↓
静态检查、语义检查和游戏内 QA
```

翻译人员和 AI 只编辑翻译数据库，不直接编辑生成 ADV。未翻译记录保持日文原文，空译文不得覆盖源文本。

## 6. 开始批量翻译前的门禁

1. 冻结官方日文基线、配置和哈希。
2. 保持历史中文版目录与正式流水线隔离。
3. 对 65,441 条主目录执行一次全量“译文等于原文”的原样回填。
4. 重新编译 Unicode SA.ALD，并验证 201 个条目、控制结构和文本语义不变。
5. 固化翻译状态、审核状态和中文术语库格式。
6. 选择一个完整场景，从日文原文重新翻译并完成端到端游戏内验证。

第 3 至第 4 项尚未形成正式全量验收报告。在其通过前，不启动大规模翻译。

## 7. 翻译与发布质量要求

- 每条译文保留稳定 ID、日文原文哈希、上下文和审核状态。
- 控制符和 `⟦ADV:n⟧` 占位符不得丢失、重复或改变顺序。
- 锁定术语必须一致，中文术语只能来自现行审核流程。
- 每次构建记录输入版本、工具版本、译文统计、ALD manifest 和 SHA-256。
- QA 覆盖字体缺字、乱码、断行、溢出、菜单、变量插值、分支、存档和读档。
- 图片中的日文另建图像汉化清单，不混入 ADV 文本管线。
- 开发阶段可继续使用微软雅黑验证显示；发布字体必须覆盖中日文并确认许可和再分发条件。
- 正式运行环境为 `xsystem35-sdl2`，不承诺兼容原版 System 3.x 引擎。
